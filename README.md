# ポケモンスリープ 食材別ポケモン検索

ポケモンスリープの各ポケモンが獲得できる食材を効率順で検索・比較できるWebアプリケーションです。

## 🎯 主な機能

- **食材別検索**: 17種類の食材から選択して、その食材を獲得できるポケモンを表示
- **効率順ソート**: 選択した食材の最大獲得量でポケモンを自動ソート
- **詳細情報表示**: 各ポケモンのA/B/C食材と獲得量を一目で確認
- **リアルタイム検索**: 遅延のない即座のフィルタリング

## 🚀 使い方

### 1. 食材を選択
画面上部の食材ボタンをクリックして、調べたい食材を選択します。

### 2. 結果を確認  
選択した食材を獲得できるポケモンが、**最大獲得量の高い順**に表示されます。

### 3. 詳細情報
各ポケモンカードには以下の情報が表示されます：

- **ポケモン名の右のアルファベット（A/B/C）**: 選択した食材がそのポケモンの何番目の食材かを表示
- **数値**: そのポケモンで選択した食材の最大獲得量（推定値）
- **A/B/C食材リスト**: そのポケモンが獲得できる全ての食材

## 📊 データについて

- **対象ポケモン**: 192体すべて対応
- **データソース**: ポケモンスリープ攻略Wiki
- **更新**: 手動更新（開発者がWikiから最新データを取得）
- **推定値の前提**: せいかく・サブスキル無補正、睡眠時間8時間半、所持数溢れ無し

## 🛠️ 技術仕様

- **フロントエンド**: React 19, Vite
- **デプロイ**: GitHub Pages
- **データ処理**: Node.js + Cheerio
- **パフォーマンス**: React.memo, カスタムフック, メモ化最適化
