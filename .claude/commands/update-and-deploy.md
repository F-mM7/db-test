## Pokemon Sleep データ更新 & デプロイ

以下の手順を実行してください：

### 1. データ更新
`npm run fetch-data` を実行して、最新のWikiデータを取得・パースします。

### 2. デプロイ
`npm run deploy` を実行して、GitHub Pagesにデプロイします。

### 3. 結果報告
- パースしたポケモン数
- デプロイの成否
を報告してください。
